3. 資料庫模型 (Models)
📍 courses/models.py
Python

from django.db import models
from django.contrib.auth.models import User  # 引用內建使用者

class Course(models.Model):
    # 常用欄位與參數
    title = models.CharField(max_length=100)                      # 短字串 (必填 max_length)
    description = models.TextField(blank=True, null=True)         # 長字串 (允許空白/空值)
    credits = models.IntegerField(default=3)                      # 整數 (可填預設值)
    is_active = models.BooleanField(default=True)                 # 布林值 True/False
    created_at = models.DateTimeField(auto_now_add=True)          # 新增時自動紀錄時間
    
    # 外鍵關聯 (一對多)
    teacher = models.ForeignKey(User, on_delete=models.CASCADE)   # 連帶刪除

    # 後台顯示名稱
    def __str__(self):
        return self.title

4. 後台管理註冊 (Admin)
📍 courses/admin.py
Python

from django.contrib import admin
from .models import Course

# 進階客製化註冊
@admin.register(Course)
class CourseAdmin(admin.ModelAdmin):
    list_display = ('title', 'credits', 'is_active', 'created_at')  # 清單顯示欄位
    list_filter = ('is_active', 'credits')                         # 右側篩選器
    search_fields = ('title',)                                     # 搜尋框搜尋目標
    ordering = ('-created_at',)                                    # 排序 (-號代表降冪)

5. 後端業務邏輯 (Views)
📍 courses/views.py
Python

from django.shortcuts import render, redirect
from .models import Course

def course_list(request):
    # 1. 處理 POST 請求 (接收表單/執行功能)
    if request.method == 'POST':
        title_input = request.POST.get('title')
        # 執行動作：寫入資料庫
        Course.objects.create(title=title_input)
        return redirect('course_list')  # 處理完自動重定向跳轉

    # 2. 處理 GET 請求 (單純看網頁/讀取資料)
    courses = Course.objects.all()      # 從資料庫撈資料
    context = {'courses': courses}      # 打包成字典傳給前端
    
    return render(request, 'courses/course_list.html', context)

6. 前端 HTML 模板 (Templates)
📍 templates/courses/course_list.html
HTML

<!DOCTYPE html>
<html>
<head>
    <title>課程列表</title>
</head>
<body>
    <h1>課程清單</h1>

    <!-- 1. 表單提交區塊 (POST 請求) -->
    <form method="POST" action="{% url 'course_list' %}">
        {% csrf_token %}  <!-- Django 安全機制，POST 表單必加 -->
        <input type="text" name="title" placeholder="輸入課程名稱">
        <button type="submit">新增課程</button>
    </form>

    <hr>

    <!-- 2. 資料印出區塊 (GET 渲染) -->
    <ul>
        {% for course in courses %}
            <li>{{ course.title }} - {{ course.credits }} 學分</li>
        {% empty %}
            <li>目前沒有任何課程</li>
        {% endfor %}
    </ul>

    <!-- 3. 超連結切換網頁 -->
    <a href="{% url 'course_list' %}">返回清單</a>
</body>
</html>

印出變數：{{ variable_name }}

邏輯迴圈/判斷：{% for %}、{% if %}

表單安全與跳轉：{% csrf_token %}、{% url 'url_name' %}

7. 常用終端機指令 (Terminal Commands)
Bash

# 1. 啟動開發伺服器

# 2. 建立新 App

8.  快速檢核卡關責任歸屬 (Debug SOP)
404 找不到網頁 ➔ 檢查 config/urls.py 與 App 的 urls.py 拼音及路徑。

405 / 表單按了沒反應 ➔ 檢查 views.py 是否有處理 request.method == 'POST' 以及 HTML 是否有 {% csrf_token %}。

網頁看得見但資料空白 ➔ 檢查 views.py 的 context 字典 Key 值與 HTML 的 {{ }} 變數名稱是否一致。

資料庫報錯 / 存不進去 ➔ 檢查 models.py 欄位型態，並確認是否有執行 makemigrations 與 migrate。
